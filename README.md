# AHR Maintenance Inventory

ระบบบริหารคลังอะไหล่สำหรับหน่วยงาน Maintenance (AHR) — เว็บแอปที่รันบนเครื่อง PC ในโรงงาน
เข้าใช้งานผ่านเบราว์เซอร์จากเครื่องไหนก็ได้ใน LAN เดียวกัน แบบ real-time

สร้างจากข้อมูลจริงในไฟล์ Excel เดิม 3 ไฟล์ (spare parts 930 รายการ, tools/facility 631 รายการ,
เครื่องจักร 179 รายการ) โดย import เข้าฐานข้อมูลอัตโนมัติ

## มีอะไรใหม่ในเวอร์ชันล่าสุด (v2.6)

**แก้การคำนวณยอดคงเหลือ (สำคัญ)**
- การทำรายการพร้อมกันหลายคน **ไม่ทำให้ยอดหายอีก** (ทดสอบ 20 รายการพร้อมกัน: เดิมหาย 17 → ตอนนี้ 0)
- ปฏิเสธจำนวน 0 / ติดลบ ทั้งการเบิกและการรับเข้า
- ไฟล์ Excel ต้นฉบับที่มีรหัสเดียวกันหลายแถว (47 รหัส) **รวมยอดทุกแถว** (เดิมนับแค่แถวสุดท้าย)
- เลขที่ใบเบิกไม่ชนกันหลังลบใบเบิก (เดิมทำให้เบิกไม่ได้ทั้งวัน) · กดยืนยันซ้ำ/รับ PO ซ้ำ ไม่ตัดหรือเพิ่มสต็อกซ้ำ · PO ที่ยกเลิกแล้วรับเข้าไม่ได้
- หน้าเบิกแสดง **ยอดคงเหลือใหม่ทันที** หลังยืนยัน
- เครื่องมือตรวจสอบ **ยอดคงเหลือเทียบกับประวัติ** + ปุ่มซ่อมแซมอัตโนมัติ (สำหรับฐานข้อมูลเดิม)

**ฟีเจอร์ใหม่**
- **ค้นหาเครื่องที่ซ่อมด้วยการพิมพ์** บางส่วน + จำเครื่องที่ใช้ล่าสุด
- **สแกน QR / บาร์โค้ดด้วยกล้องมือถือ** (กล้องสด หรือถ่ายรูป) — อ่านบาร์โค้ดผู้ผลิตแล้วค้นจากเบอร์อะไหล่ได้
- **รูปอะไหล่** (แอดมินเพิ่ม/เปลี่ยน/ลบ) แสดงในหน้าเบิก ตะกร้า คลัง รับเข้า ใบเบิก และบัตรอะไหล่ · เก็บในฐานข้อมูล ไม่หายบน Render
- **รูปแนบใบเบิก** ย่อขนาดอัตโนมัติและเก็บในฐานข้อมูล (เดิมรูปจากมือถือใหญ่เกินและหาย)
- **สร้างอะไหล่ใหม่จากหน้ารับเข้า** แล้วรับเข้าต่อได้ทันที · บัตรอะไหล่พร้อมประวัติความเคลื่อนไหว
- เบิกทศนิยมได้ (เช่น 0.5 เมตร)
- มือถือ/แท็บเล็ต (≤1024px) เมนูเป็น ☰ เสมอ · หน้าต่างแก้ไขมีปุ่มบันทึกอยู่ด้านล่างตลอด · บังคับโหลดหน้าเว็บเวอร์ชันล่าสุด

## มีอะไรใหม่ในเวอร์ชันก่อนหน้า (v2.5)

**ฟีเจอร์ใหม่**
- **สร้างอะไหล่ใหม่** (แอดมิน) — ปุ่ม "+ เพิ่มอะไหล่ใหม่" ในหน้าคลังอะไหล่ พร้อมตรวจรหัสซ้ำ และลบอะไหล่ที่สร้างผิดได้
- **คืนอะไหล่** (หัวหน้า/แอดมิน) — เมนูใหม่ คืนของเข้าคลังพร้อมเหตุผล ใบเบิกมีหมายเหตุการคืนกำกับ และสรุป/ส่งออก Oracle หักยอดคืนให้อัตโนมัติ
- **ดูแลระบบ** (แอดมิน) — ข้อมูลระบบ, สำรองทั้งหมด (Excel/.db), กู้คืนจากไฟล์สำรอง, ตรวจสอบคุณภาพข้อมูลพร้อมแก้ไขอัตโนมัติ, แจ้งเตือนบัญชีรหัสผ่านเริ่มต้น
- **ล้าง/รีเซ็ตข้อมูล** — ยืนยัน 2 ครั้ง (ต้องพิมพ์ "ยืนยันล้างข้อมูล"): ลบข้อมูลทดสอบแล้วคืนยอดคงเหลือเดิม · รีเซ็ตเป็นข้อมูลตั้งต้น · ล้างทั้งหมด · ล้าง Audit log
- **ลบใบเบิก** (แอดมิน) — คืนยอดสต็อกที่ตัดไปให้อัตโนมัติ
- **รองรับมือถือ/แท็บเล็ต** — เมนูแบบ ☰ (Hamburger)

**แก้ไขข้อผิดพลาด**
- สลับผู้ใช้แล้ว **เมนูด้านซ้ายค้างเป็นของผู้ใช้เดิม** → เมนูเปลี่ยนตามสิทธิ์ทุกครั้ง
- ปุ่ม **พิมพ์/PDF หน้าว่าง** (หน้าส่งออก Oracle) → แก้แล้ว และทุกปุ่มพิมพ์ไม่ใช้ pop-up อีกต่อไป
- **เวลาไม่ตรงเวลาไทยบนเว็บ** → แสดง/กรอง/ออกเลขที่/ส่งออก เป็นเวลาไทยทั้งหมด
- ส่งออก Oracle แบบ **Excel ไม่กรองตามช่าง** → แก้แล้ว (CSV/Excel/สรุป ใช้เงื่อนไขเดียวกัน)
- ไฟล์ CSV เปิดใน Excel แล้ว **ภาษาไทยเพี้ยน** → เพิ่ม BOM ให้แสดงไทยถูกต้อง
- ลบข้อความรหัสผ่านเริ่มต้นออกจากหน้า Login

**อัปเดตบน Render/Neon:** อัปโหลดไฟล์ชุดใหม่ขึ้น GitHub ตามปกติ — ฐานข้อมูลเดิมจะ **อัปเกรดตัวเองอัตโนมัติ** (เพิ่มตาราง/คอลัมน์ใหม่) โดยข้อมูลไม่หาย

## โครงสร้างข้อมูล (ต่างจาก Excel เดิมอย่างไร)

Excel เดิมเก็บ **ยอดคงเหลือรายเดือนเป็นคอลัมน์** (Receive/Requisition/Balance ต่อกันไป 12 เดือน)
ระบบใหม่เปลี่ยนเป็น **บัญชีเดินสะพัด (ledger)** ทุกการรับ/เบิก/ปรับ = 1 transaction ที่ย้อนตรวจได้:

```
items ──< stock_txn        (ทุก on_hand มาจากผลรวม ledger — ตรวจสอบย้อนได้)
  │
  └──< req_line >── requisitions ──> users / machines
```

ตอน import จะทำให้อัตโนมัติ:
- แยก Description ที่อัดหลายฟิลด์ (`กลุ่ม \\ ชื่อ : เบอร์อะไหล่ \\ ยี่ห้อ`) ออกเป็นคอลัมน์
- ล้าง UOM ที่พิมพ์ไม่ตรงกัน (Pcs/PCS/pcs/Pcs. → Pcs)
- นำ Machine list มาเป็น dropdown มาตรฐาน (แก้ปัญหา Machine เดิมที่เป็น free-text)
- คำนวณ Reorder Point จากอัตราการเบิกเฉลี่ย × lead time (ไม่ต่ำกว่า min เดิม)

**Re-import ใหม่ได้ทุกเมื่อ:** `python -m scripts.import_excel --dir source` (upsert ตาม item_code)

## การแจ้งเตือน (ตั้งค่าใน `.env`)

เปิดใช้เฉพาะช่องที่ใส่ค่า — เว้นว่างคือปิด
- **Discord** — สร้าง Webhook ของห้อง แล้ววาง URL ที่ `DISCORD_WEBHOOK`
- **Telegram** — คุยกับ @BotFather เอา token, ใส่ `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID`
- **LINE** — ใส่ `LINE_CHANNEL_ACCESS_TOKEN` + `LINE_NOTIFY_TARGET` (กลุ่ม/ผู้รับสรุป)
- **WebSocket** — เปิดในเว็บอัตโนมัติ (จุดสีเขียว "real-time" มุมบนขวา)

สรุปสิ้นวันส่งอัตโนมัติเวลา `EOD_HOUR:EOD_MINUTE` (ค่าเริ่ม 18:00 เวลาไทย)

## การเชื่อม LINE เพื่อป้อนเบิก-รับของ (ข้อ 11 — บทวิเคราะห์)

Technician/Engineer ส่วนใหญ่ส่งข้อมูลทาง LINE อยู่แล้ว จึงควรให้ **เบิกผ่าน LINE ได้โดยไม่ต้องเปิดเว็บ**
แนวทางที่แนะนำ (เรียงตามความคุ้มค่า):

**วิธีที่แนะนำ — LINE Messaging API + Webhook (มีโครงไว้แล้วในระบบ `/line/webhook`)**
1. สร้าง LINE Official Account + เปิด Messaging API ใน LINE Developers Console
2. ตั้ง Webhook URL ชี้มาที่เซิร์ฟเวอร์นี้ (ต้องเปิดออกอินเทอร์เน็ต — ใช้ reverse proxy/ngrok/Cloudflare Tunnel เพราะ LINE ต้องเรียกเข้ามาได้)
3. ผูกบัญชี LINE กับผู้ใช้ในระบบผ่าน `users.line_user_id` (ทำ flow "พิมพ์รหัสผูกบัญชี" ครั้งเดียว)
4. รูปแบบข้อความที่รองรับ (ออกแบบไว้):
   - เบิก: `เบิก MSP0005324A 2 เครื่อง Komatsu 800T ปัญหา วาล์วรั่ว`
   - ค้นหา: `ค้นหา valve komatsu` → บอตตอบรายการให้เลือก (พร้อมปุ่ม Quick Reply)
   - รับเข้า (เฉพาะ leader): `รับเข้า AFS0001278A 10`
   - แนบรูป: ส่งรูปตามหลังใบเบิกล่าสุด → เก็บเป็น photo ของใบนั้น
5. บอตตอบกลับยืนยัน + ตัดสต็อก + ยิงแจ้งเตือนเหมือนเบิกผ่านเว็บ (ใช้ logic เดียวกัน)

**ข้อควรรู้:**
- LINE Messaging API (push/reply) ฟรีในโควตาหนึ่ง เกินโควตามีค่าใช้จ่าย
- เพื่อความแม่นยำ แนะนำใช้ **Quick Reply/Flex Message** ให้ผู้ใช้ "เลือก" อะไหล่แทนการพิมพ์รหัสเอง (กันพิมพ์ผิด)
- ทางเลือกเสริม: LINE LIFF (เปิดหน้าเว็บฟอร์มย่อในแอป LINE) เหมาะถ้าอยากได้ฟอร์มเต็มแต่ยังอยู่ใน LINE

ในโค้ดปัจจุบัน LINE bot ทำงานครบแล้ว: ตั้งค่า Token/Secret ในหน้า 'ตั้งค่าแจ้งเตือน' แล้วชี้ Webhook URL มาที่ `<public-url>/line/webhook` ผ่าน Cloudflare Tunnel/ngrok — ผู้ใช้พิมพ์ 'เบิก' ในแชทเพื่อเริ่ม

## การทำเป็นตัวติดตั้งคลิกเดียว (ข้อ 12 — แผน)

Phase 1 ใช้ `run.bat` (ต้องมี Python) — สำหรับผู้ใช้ที่ไม่มี Python มีทางเลือก:

1. **PyInstaller** — รวมเป็น `AHR-Inventory.exe` ไฟล์เดียว ดับเบิลคลิกรันเซิร์ฟเวอร์ + เปิดเบราว์เซอร์
   `pyinstaller --onefile --add-data "web;web" --add-data "data;data" launcher.py`
2. **ห่อด้วย Inno Setup** — ได้ `Setup.exe` มี shortcut บน Desktop/Start Menu, ตั้งให้รันตอนเปิดเครื่อง
3. **ทำเป็น Windows Service** (NSSM) — ให้รันเบื้องหลังตลอด ผู้ใช้ไม่ต้องเปิดหน้าต่างเลย

แนะนำ: PyInstaller + Inno Setup ได้ประสบการณ์ "ถัดไป-ถัดไป-เสร็จ" ที่ผู้ใช้ทั่วไปคุ้นเคย

## แก้ปัญหาที่พบบ่อย (Troubleshooting)

**เปิดแล้วเจอหน้า login ของโปรแกรมอื่น (เช่น AL Production Andon)**
= มีโปรแกรมอื่นจับพอร์ตนั้นอยู่ก่อน ระบบนี้ตั้งค่ามาที่พอร์ต **8770** เพื่อเลี่ยงการชน
ถ้ายังชนอีก ให้แก้ `PORT=` ใน `.env` เป็นเลขอื่น (เช่น 8771) แล้วเปิดใหม่

**ติดตั้งค้าง / ขึ้น `No module named uvicorn` หรือ `openpyxl`**
= การติดตั้งรอบก่อนไม่สำเร็จ วิธีแก้: ลบโฟลเดอร์ `.venv` ทิ้ง แล้วดับเบิลคลิก `run.bat` ใหม่
(ตัว `run.bat` เวอร์ชันนี้จะล้างของเก่าที่ค้างและติดตั้งใหม่ให้เองอัตโนมัติ)

**ขึ้น `PydanticUserError: Field 'id' requires a type annotation` / เปิดแล้ว connection refused**
= ปัญหาความเข้ากันของ Python 3.14 เวอร์ชันนี้แก้แล้ว (เปลี่ยนมาใช้ SQLAlchemy ล้วน รองรับ Python 3.10–3.14)
ถ้าเคยแตกไฟล์เวอร์ชันเก่าไว้ ให้ลบโฟลเดอร์ `.venv` เดิมทิ้งก่อน แล้วดับเบิลคลิก `run.bat` ใหม่

**ต้องมี Python ก่อน** — ถ้าเครื่องยังไม่มี ให้ลงจาก python.org แล้วติ๊ก "Add Python to PATH"
(หรือรอ Phase 2 ที่ทำเป็น `.exe` ให้ไม่ต้องลง Python เอง)

**เปิดจากเครื่องอื่นใน LAN ไม่ได้** = Windows Firewall อาจบล็อก ให้อนุญาต Python/พอร์ต 8770
